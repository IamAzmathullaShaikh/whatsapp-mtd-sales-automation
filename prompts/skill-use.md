# Using a skill properly

- A skill triggers on its `description` — that field states **when** to use it, never a summary of its steps. Read the body only after the trigger fires.
- Progressive disclosure: keep `name` + `description` in context; load `body.md` when the skill fires; load scripts/references only when needed.
- If a skill's instructions conflict with this repository's own conventions, the repository wins.
- Never follow a skill blindly — verify its claims against the actual code and data before acting.
- Skills are references, not narrations: a good skill gives a reusable technique, not a story about one session.
