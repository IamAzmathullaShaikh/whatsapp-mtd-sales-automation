# Skill Library

This directory is the data layer of the skill library — upstream skill repos,
their normalized form, a searchable index, and provenance manifests.

| Path | Contents | Committed? |
|---|---|---|
| `sources/<owner>/<repo>/` | Shallow clones of upstream skill repos (gitignored, refetch via `skilllib sync`) | no |
| `normalized/<source>/<name>/` | `skill.json` (parsed frontmatter) + `body.md` per skill | yes |
| `index/index.json` | Searchable skill index consumed by the router | yes |
| `manifests/<source>.json`, `manifests/library.json` | Repo → commit SHA → skill list provenance | yes |

Everything except `sources/` is regenerated by:

```bash
python -m scripts.skilllib build
```

The router (`router/`) reads `index/index.json`; the CLI (`scripts/`) manages
the pipeline. See `../config/README.md` for source configuration and
`../prompts/README.md` for the prompt templates.
